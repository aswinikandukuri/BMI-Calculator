# BMI-Calculator
Python GUI Based Health Application
🔍 Project Description

The BMI Calculator is a desktop-based health application developed using Python and Tkinter as part of my Internship Project at Infosys.
This project demonstrates the practical implementation of Python programming concepts by converting a mathematical health formula into an interactive, user-friendly graphical application.

The application calculates a user’s Body Mass Index (BMI) based on height and weight inputs and categorizes the result according to internationally accepted BMI standards. It focuses on clean UI design, accurate computation, and robust error handling. 
          
🧩 Key Features

📥 Accepts height (meters) and weight (kilograms)

🧮 Computes BMI using the standard formula

🏷️ Displays health classification instantly

⚠️ Validates incorrect or invalid user inputs

🧹 Clear/reset input functionality

ℹ️ “About” section describing the application    

📐 BMI Classification Logic

Underweight: BMI < 18.5

Normal Weight: 18.5 – 24.9

Overweight: 25 – 29.9

Obese: ≥ 30
